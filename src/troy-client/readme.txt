Short Description: Troy Client enables updating your WordPress plugins and themes from decentralized Troy Server repositories.

== Description ==

Troy Client is a WordPress plugin that connects your site to Troy Server repositories, enabling automatic updates for plugins and themes hosted outside WordPress.org.

With Troy Client, you can:

* Connect to multiple Troy Server repositories
* Receive automatic plugin and theme updates
* Manage repository connections from your dashboard

== Installation ==

Troy Client is not available on WordPress.org.

1. Download the latest version from [repo.deploytroy.org](https://repo.deploytroy.org/plugin/get/zip/troy-client).
1. Upload the ZIP file via Plugins > Add New > Upload Plugin.
1. Activate the plugin through the Plugins menu.
1. Add your Troy Server repository URLs under Settings > Troy Client.

= Requirements =

* WordPress 6.7 or higher
* PHP 7.4 or higher

= Multisite =

Troy Client requires network activation on WordPress Multisite installations.
