== Description ==

Troy Server is a WordPress plugin that enables plugin and theme developers to distribute their packages to users running Troy Client.

With Troy Server, you can:

* Host your own plugin repository
* Manage plugin versions and updates
* Control access to your packages
* Distribute plugins independently from WordPress.org

== Installation ==

Troy Server is not available on WordPress.org.

1. Download the latest version from [repo.deploytroy.org](https://repo.deploytroy.org/package/get/zip/troy-server).
1. Upload the ZIP file via Plugins > Add New > Upload Plugin.
1. Activate the plugin through the Plugins menu.
1. Configure your repository settings under Settings > Troy Server.

= Requirements =

* WordPress 6.8 or higher
* PHP 8.4 or higher
