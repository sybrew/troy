This installer package is part of the Troy project, a WordPress plugin deployment and management system. Activate this plugin to quickly install Troy Client and plugins and themes required by the distributor of this package.

== Description ==

This installer package is automatically generated by the Troy Server.

It installs Troy Client and vendor plugins required by the distributor of this package.

This installer may be configured to automatically deactivate or even delete itself after installation, depending on the settings defined in the Troy Server.

== Installation ==

You can either install the plugin via your WordPress dashboard or via FTP.

### Install via WordPress

1. Log in to your WordPress Dashboard.
2. Go to Plugins > Add New.
3. Click "Upload Plugin" at the top.
4. Upload the ZIP file this installer came in.
5. Click "Install Now" next to the uploaded file.
6. Once installed, click "Activate Plugin".
7. You may see a notification about the plugin's installation process.

### Install via FTP

1. Unzip this ZIP file's contents to an easily accessible location, like on your desktop.
2. Connect to your website via FTP.
3. Browse to [...]/wp-content/plugins/.
4. Transfer this folder from to your server. You should find this readme.txt at [...]/wp-content/plugins/[this-folder]/readme.txt.
5. Go to your WordPress plugin dashboard to verify the transfer.
6. Activate the plugin.
7. Note: This plugin may be configured to automatically deactivate or even delete itself.
